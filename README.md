# BRICKLINE WORKS

A fictional contractor portfolio organized as project ledgers, site records and specification sheets. Project names and records are fictional; photographs are documentary references and do not imply client relationships.

## Photography

Local optimized WebP files from Pexels, used under the [Pexels license](https://www.pexels.com/license/):

- `site.webp` — Peter Dyllong, “Concrete construction site with building materials”: https://www.pexels.com/photo/concrete-construction-site-with-building-materials-36162732/
- `warehouse.webp` — Mike van Schoonderwalt, “Empty Concrete Warehouse”: https://www.pexels.com/photo/empty-concrete-warehouse-5505927/
- `materials.webp` — Pixabay, “Empty Concrete Building” (CC0 source listing): https://www.pexels.com/photo/empty-concrete-building-236705/

## Development

`npm install` then `npm run dev`. The app is frontend-only and uses hash-safe routes.
